议论文智批系统

Essay Grader Platform · 议论文智能批改与教学辅助系统（功能框架）
面向中学语文教师的一站式教学辅助平台 —— 覆盖「智能出题 → 深度批改 → 学情跟进 → 教学资源」全流程
核心工作流→AI 初筛批改→教师复核·终审→结果沉淀与学情分析
📊
01 · WORKBENCH
工作台总览
教师日常批改入口 · 全局数据驾驶舱
  • ▪复核任务流：待复核 / 已复核 一目了然
  • ▪批改统计：得分分布、批改量趋势
  • ▪高频错误标签：快速定位教学薄弱点
👥
02 · CLASS
班级管理
班级 · 学情 · 个性化 三合一
  • ▪班级与学生：建班 / 批量导入学生
  • ▪班级学情报告：平均分 · 批改次数 · 薄弱点
  • ▪错题本与个性化：个人错题 · 学习路径
🧠
03 · QUESTION BANK
智能出题中心
真题 / 模拟卷 + AI 生成 一体化题库
  • ▪查找题库：高考真题 + 模拟卷 合并查询省份/年份/考试类别/话题/思辨类型
  • ▪模仿出题：以某题为蓝本，模仿/替换话题与思辨类型生成新题
  • ▪自定义出题：输入材料 / 想法，AI 生成完整作文题
  • ▪我的题库：收藏 / 保存 / 批量导入 / 分类管理
🖊️
04 · GRADING
批改工作台
议论文深度批改 —— 逻辑拆解 + 论据核验
  • ▪结构拆解：引论 / 本论 / 结论 骨架 + 异常标红
  • ▪逻辑分析：偷换概念 · 论据偏离 · 循环论证 等谬误识别
  • ▪论据核验：事实核查 → 正确 / 存疑 / 有误
  • ▪评分与评语：内容40·表达40·发展20 + 雷达图 + 逐句建议
💡
05 · SCAFFOLD
写作框架辅助
写前脚手架 · 降低构思门槛
  • ▪按题生成框架：开头 → 分论点 → 结尾
  • ▪要素建议：核心品质 · 适用素材 提示
  • ▪与题库 / 素材库联动，随取随用
📚
06 · MATERIALS
素材库
白名单素材 · 支撑论据核验
  • ▪四大类素材：人物 / 事件 / 名言 / 数据
  • ▪来源核验：来源标注 · 白名单 · 待核验状态
  • ▪按思辨维度组织，批改 / 支架随取随用
⚙️ 技术底座
前端：React 18 · TypeScript · Tailwind CSS · Vite
后端：Node.js · Express · TypeScript REST API
AI 引擎：DeepSeek 真实模型 / 本地 Mock 演示 双模式
数据：JSON 文件存储（可平滑迁移 PostgreSQL）
